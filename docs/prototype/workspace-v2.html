Spec cơ chế — hợp đồng để code

Mô hình: Thư mục = ngữ cảnh (context), không phải bộ lọc. Một context có 2 view: Danh sách và Bảng. Bộ lọc (trạng thái / loại / quan trọng / tìm kiếm) áp bên trong context hiện tại.

1Routing

  • View Danh sách: / · View Bảng: /kanban
  • Context qua query: ?folder={folderId}. Không có folder = context Tất cả mục.
  • Filter (status/type/search) là state trong page, không nằm trên URL.

2Bất biến điều hướng

  • Đổi view giữ context: toggle Danh sách ⇄ Bảng phải mang theo ?folder=.
  • Đổi context giữ view: click thư mục ở sidebar giữ nguyên đang ở / hay /kanban.
  • Từ trang khác (Gửi email…) click thư mục → về view Danh sách /?folder=.
  • Xoá thư mục đang xem → tự về Tất cả mục (giữ view).

3Sidebar — active duy nhất

  • Tại mọi thời điểm chỉ một mục sáng: hoặc Tất cả mục, hoặc đúng 1 thư mục.
  • Tất cả mục sáng ⟺ đang ở / hoặc /kanban và không có ?folder=.
  • Mỗi thư mục hiện itemCount (ẩn khi hover để nhường nút menu ⋯).
  • Kéo item/row thả vào thư mục = gán vào thư mục (highlight khi kéo qua).

4Header trang = context

  • Tiêu đề: Tất cả mục hoặc chấm màu + tên thư mục.
  • Subtitle: Thư mục · N mục / N mục; Bảng thêm «kéo-thả thẻ để đổi trạng thái».
  • Thư mục không xuất hiện trong dải chip «Đang lọc» (nó không phải filter).
  • Chip thư mục trên từng item: ẩn chip của thư mục đang đứng trong (giảm nhiễu).

5Từ ngữ thống nhất

  • Không dùng chữ «Inbox» trong UI (đụng tên status). Context mặc định = Tất cả mục.
  • Status: Inbox→Cần xem · Doing→Đang xử lý · Done→Hoàn thành.
  • Chip «mọi…» thay «Tất cả» lặp lại: Mọi trạng thái / Mọi loại.
  • Email đã đọc ở trạng thái Cần xem hiển thị «Đã xem».

6Empty states (3 loại)

  • Có filter: «Không có mục nào khớp bộ lọc» + nút Xoá bộ lọc.
  • Thư mục trống: hướng dẫn kéo-thả từ Tất cả mục (xem thư mục «Khách hàng B» trong demo).
  • Chưa có dữ liệu: hướng kết nối dịch vụ + Đồng bộ.
